# 데일리 개발로그 — 식집사 2.0

세션마다 짧게 기록. 트러블슈팅·스펙 변경 이력도 여기 한 항목으로 같이 남긴다.
양식은 기획서 3단계 ④ 기준, 최신 항목을 맨 위에 추가한다.

> 이 문서는 **무엇을·왜** 했는지만 남긴다. 결정의 배경과 근거는 `spec.md` 결정 로그,
> 구현 세부는 코드와 커밋 메시지를 본다. 여기에 다시 옮겨 적지 않는다.

```
## YYYY-MM-DD
- 오늘 목표:
- 진행한 작업:
- 막힌 점 / 트러블슈팅:
- 스펙과 다르게 구현한 부분(있다면) + 이유:
- 내일 할 일:
```
