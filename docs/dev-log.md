# 데일리 개발로그 — 식집사 2.0

세션마다 짧게 기록. 트러블슈팅·스펙 변경 이력도 여기 한 항목으로 같이 남긴다.
양식은 기획서 3단계 ④ 기준, 최신 항목을 맨 위에 추가한다.

> 이 문서는 **무엇을·왜** 했는지만 남긴다. 결정의 배경과 근거는 `spec.md` 결정 로그,
> 구현 세부는 코드와 커밋 메시지를 본다. 여기에 다시 옮겨 적지 않는다.

```
## YYYY-MM-DD
- 오늘 목표:
- 진행한 작업:
- 막힌 점 / 트러블슈팅:
- 스펙과 다르게 구현한 부분(있다면) + 이유:
- 내일 할 일:
```

**오늘 목표** — 11번 ① 뒤에 남아 있던 UX 수정분 마무리 → ② 파비콘·링크 공유 미리보기

**진행한 작업**
- **"밀린 일정"을 일급 상태로 승격** — 지금까지 지난 일정은 예정일 날짜만 보여줘서 밀린 건지 알 수 없었음
  - SC-03 할일 카드에 `n일 지남`을 라임으로 표기, 90일 넘게 밀리면 `2026년 3월부터 밀림`(연·월)으로 — 기존 `dday()` 하나로 통일
  - SC-05 캘린더는 밀린 항목을 원래 날짜에만 두지 않고 **오늘 칸으로 끌어와** "밀림" 배지 + 원래 예정일 병기. 보이는 달 밖의 밀린 항목까지 별도 조회
  - 완료 직후에도 오늘 칸에서 사라지지 않게 조회 조건을 `미완료 OR 오늘 완료`로 확장
- SC-06 리스트 카드에 "분갈이 시기" 배지 — 상세에 들어가야만 알 수 있던 상태를 리스트로 끌어올림
- 캘린더 날짜 칸 점이 3개를 넘으면 `+n`으로 접기, 선택된(블랙) 칸에서 완료 점이 묻히던 것 보정
- 전 탭 sticky 제목에 스크롤 경계 그림자, SC-03 알림 배너를 라벤더 면 → 좌측 보더로(면을 덜 먹게)
- CLAUDE.md에 이번 라운드 규칙 5건 추가 + 이미 쓰고 있으면서 표에 빠져 있던 `soil` 토큰 문서화

**막힌 점 / 트러블슈팅**
- 밀린 항목을 완료하면 오늘 칸에서 사라졌음 — 완료 시 `scheduled_date`는 그대로라 원래 날짜로 돌아가 버림. 조회 조건에 "오늘 완료"를 더해 해결
- 캘린더 밀림 항목이 원래 날짜 칸에서도 "예정 2026-03-01"을 달아 제목과 중복 → 오늘 칸으로 끌어온 경우만 병기
- 남은 lint 에러 5건(`react-hooks/set-state-in-effect`)은 sc03·sc05·sc07·sc11의 기존 `useEffect` → `load()` 패턴. 이번 변경과 무관해 손대지 않음(사용자 판단으로 뒤로 미룸)
- 아이콘을 만들 도구가 없었음 — 이 맥에 ImageMagick·PIL이 없고 `sips`는 합성이 안 되며, 브라우저는 `file://`을 못 열고 스크린샷도 JPEG라 아이콘용으로 부적합. 결국 캔버스로 그려 임시 API 라우트로 저장하는 방식(작업 후 라우트 삭제). `app/api/_devsave`로 만들었다가 404 — App Router에서 `_` 폴더는 라우팅 제외라 `devsave`로 변경

**11번 ② 파비콘·링크 공유 미리보기**
- Next.js 기본 아이콘을 걷어내고 로고(`logo_icon.png`)에서 4종 파생 — `icon.png`(256, 투명) · `favicon.ico`(64) · `apple-icon.png`(180, 라임) · `opengraph-image.png`/`twitter-image.png`(1200×630)
- 배경을 라임/흰/ink/투명 4안으로 만들어 16·24·32px에서 나란히 비교 → **투명 풀블리드** 확정. 라임은 초록 새싹이, ink는 갈색 화분이 배경에 묻혔다
- OG 카드는 SC-01 입구 화면을 그대로 옮긴 구성(ink 배경 · 라임 락업 · 같은 카피)
- `layout.tsx`에 `metadataBase`·`openGraph`·`twitter` 메타 추가

**스펙과 다르게 구현한 부분**
- 밀린 항목이 캘린더에서 원래 날짜와 오늘 두 곳에 점으로 찍힘 — 원래 날짜에 일정이 있었다는 사실도 남겨야 해서 의도한 중복

**내일 할 일**
